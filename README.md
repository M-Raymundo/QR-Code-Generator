## Gerador de QR Code 📱
- Um utilitário simples e eficiente em Python para gerar imagens de QR Code personalizadas a partir de qualquer texto ou link.

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Python 3.

- **qrcode:** Para a geração da matriz do código.

- **Pillow (PIL):** Para o processamento e armazenamento da imagem final.

## 🖥️ Como Instalar
**Pré-requisitos**
- Python 3 instalado.
- Pip (gestor de pacotes).

**Instale as dependências necessárias:**

```bash
pip install -r requirements.txt
```

## 💻 Como Usar
**Para gerar um QR Code, basta executar o script principal:**

*(Nota: Dentro do arquivo qrCodeGenerator.py, é necessário que insira o link/texto diretamente na variável ```token```)*

```bash
python qrCodeGenerator.py
```
